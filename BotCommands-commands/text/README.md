# BotCommands module - Text commands
Support for text commands using annotated and declarative handlers.

## Installation
[![BotCommands-commands-text on maven central][bc-module-maven-central-shield] ][bc-module-maven-central-link]
### Maven
```xml
<dependencies>
  <dependency>
    <groupId>io.github.freya022</groupId>
    <artifactId>BotCommands-commands-text</artifactId>
    <version>VERSION</version>
  </dependency>
</dependencies>
```

### Gradle
```gradle
repositories {
    mavenCentral()
}

dependencies {
    implementation("io.github.freya022:BotCommands-commands-text:VERSION")
}
```
